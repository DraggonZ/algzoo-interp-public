Accuracy without sampling

Jacob Hilton's proposed test of an explanation, shown step by step on ARC's network.

ARC's network reads ten random numbers, one at a time, and names the position of the second-largest. It is right on 95.3% of lists. The usual way to get that number is to run the network on many random lists and count. Hilton proposes computing it instead, from the explanation alone. If the computed number comes out close to 95.3%, the explanation has captured what matters.

Top: sampling treats the network as a black box. Bottom: propagation never runs the network. It carries a probability distribution forward step by step, using a formula for each neuron. Whatever a formula misses is added as noise.

1Track a few quantities, not sixteen neurons

The inputs are random, so after each step the network's sixteen neuron values are random too. They are not sixteen separate random things, though. Our explanation says most neurons are formulas of a few shared quantities: the largest number so far, when it arrived, the second-largest, and so on. So the calculation keeps one distribution over those quantities.

The simplest is the largest so far. Its update rule is exact: the new largest is the bigger of the old one and the new number. So the chance that it is still below some value a after t numbers is the chance that each of the t numbers was, multiplied together.

The calculation also needs to know when the largest arrived, because some neurons change with its age. This part is easy too. Each step is equally likely to hold the largest. And when it arrived says nothing about how big it is. For example, at the last step the largest averages when it arrived in the first five steps and when it arrived later. So the two can be tracked separately.

2Each neuron becomes a formula

Next, each neuron is written as a formula of the tracked quantities. Take the store neuron. It holds about 17.6 times the largest number seen before the current step. It lags by one step, because it hears about a new largest from the detector neuron. Each dot below is one list at one step.

The dots sit close to the dashed line "17.6 × the largest" while the largest is young. Older largests (orange and red) fall below the line: the store fades. A formula for the store has to know the largest's age, not just its value.

3What a formula misses becomes noise

No formula is exact. The leftover, the real value minus the formula, is added to the calculation as random noise and carried forward. This is honest only if the leftover looks like noise: centred on zero and not pushing the same way on every list. The figure compares two store formulas. Each bar shows the leftover on lists whose largest has a given age. The thick part covers the middle half of lists; the thin line covers 80%.

This is why our first rough try failed. We wrote the store and detector as an exact running maximum and treated the gaps as random noise. That predicted 60–80% accuracy instead of 95%. The gaps were not random. The fade pushes the same way on every list, and this network turns small one-way errors into large changes in its answer. Stopping the fade alone drops the network to 85%.

4At the end: ten scores, tracked together

After the tenth number, the network gives each position a score and names the highest. The calculation therefore ends with a distribution over the ten scores. The predicted accuracy is the chance that the right position's score is highest. Call the right score minus another position's score the right answer's lead over that position. The answer is right when all nine leads are positive.

These scores must come out of one shared distribution, not ten separate ones. The figure shows why, using the right answer's score against the score of the largest number's position, its main rival.

The leads move together because they are built from the same few quantities. A calculation that tracks those quantities keeps the link automatically.

5Weight noise uses the same calculation

Hilton's second test adds a small random number to each of the 432 weights and asks how much accuracy drops. ARC's standard noise has a standard deviation of 0.0025 per weight. It costs between 1 and 20 points, depending on the draw. In the propagation, extra weight noise is just more leftover in step 3. It is added to each formula's noise, and the same calculation predicts the lower accuracy.

We can already predict those drops accurately, but not this way. A straight-line estimate from the network's own gradients predicts each noisy copy's accuracy within about a quarter of a point. It shows the damage is predictable. It does not use the explanation, so it does not test it.

Cancelling neurons (1, 6, 7, 8)Mostly. Each holds about 11–13 × (a reference number minus the new number). The reference mixes the previous and current largest, depending on age. With this rule in place of the four neurons, accuracy is 94.4% against 95.4%. The rule still has 648 numbers read off the network.
Memory (0, 3, 10–15)Half. While no neuron switches off, it turns its contents in a fixed, exactly linear way. When each neuron switches off is the hard part. A detailed rule gives 93.6%, but it has about 8,300 numbers read off the network. A short table by step and age gives 87%.
Gates (5 and 9)Mostly. The late gate (neuron 9) is off unless a new largest arrives, then holds about 1.5 × it; a rule built on that loses under 1 point. The keep gate (neuron 5) keeps a number if it is a new largest or at least about 0.7 × the second-largest; that on/off rule alone loses almost nothing. But its exact value matters, and the rule for the value has about 550 numbers read off the network.
Ten scores, then accuracyNot yet. The scores are formulas of the same quantities. The last step is a single integral.

An earlier estimate already avoids sampling. It keeps only the three largest numbers and computes accuracy exactly from their distribution. It misses by under one point on average. But it rests on "only the three largest matter", not on each neuron's formula, so it is not yet Hilton's test. The next step is to compute with the formulas above in place of that shortcut, then see how far the result lands from 95.3%.
