The Second-Largest Machine

A tiny recurrent network reads ten numbers, one per step, and names the position of the second-largest. It never tracks the second-largest directly. Every number big enough to matter leaves a vote for its own position in a rotating memory. Four hiding neurons cancel the vote of the current largest. When a bigger number arrives it switches them off, so the old largest's vote appears exactly when it becomes the second-largest. Watch the votes build up below, then switch parts off to see why each one is there. Every number on this page is computed from ARC's real weights.

Each bar is one position's score, split by the group it comes from; ▲ marks the total, and the highest total is the answer. The memory's vote for the largest and the hiding neurons' cancellation of it sit at the same position. When the largest is overtaken, the cancellation moves to the new largest and the old vote shows. Padding with zeros makes a real ten-number list, so these are the network's real scores for that list.
