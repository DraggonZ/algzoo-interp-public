# Prior work on the shift-register test and the size-matched rebuild

Literature check, 17 October 2026. It covers two findings about ARC's 16-neuron network that names the position of the second-largest of ten numbers. Every quote below was read at its source unless marked otherwise.

## Summary

Both findings are partly new. The ideas behind them are known. The specific tests are not, as far as this search could find.

- **Shift-register test: partly new.** Others have found delay lines inside trained recurrent networks, sometimes written in a rotated basis. One paper even builds the slots of such a register by pushing the readout weights through the recurrent matrix. We found no prior work that uses the readout rows a network learned for different output positions as a test: is each row the previous one pushed one step through the dynamics? On this network the test also corrects an earlier claim. Martin Keane concluded it is "Not a Delay Line", but his test could not detect a rotating delay line.
- **Size-matched rebuild: partly new.** Building a network by hand to test an explanation is established practice. The best-known case is Curve Circuits. We found no earlier hand-built network with exactly the trained network's size that copies every neuron's role. The nearest is Zihao Chen's 21-neuron build, which matches three of the trained network's neurons.

## (A) Readout rows linked by the dynamics

**What the test says.** Within the most common on/off pattern, the network updates its state linearly: the next state is the matrix M times the current one. Let row k of the output weights be the readout for position k. If row k+1 equals row k times M, then reading position k one step later gives the same value as reading position k+1 now. So the whole pattern of output scores slides down by one position each step. In linear-systems theory, a chain of rows built this way (C, CA, CA², …) is called the observability matrix. That mathematics is textbook. Using it to check a trained network is the new part.

**What is known.**

- Trained recurrent networks are understood by linearizing them near fixed points (Sussillo and Barak 2013). One study checks that a readout lines up with the dynamics: in sentiment networks, the line of fixed points "was aligned with the readout weights" (Maheswaranathan et al. 2019).
- Theory says the best linear memories hide a feedforward chain, that is, a delay line (Ganguli, Huh and Sompolinsky 2008; Goldman 2009). Trained memory networks show this chain (Orhan and Ma 2019).
- Trained networks can hold delay lines in a rotated basis. Foerster et al. (2017) rotate a trained switching linear network until its "delay-line dynamics" show. Henaff, Szlam and LeCun (2016) explain copying by recurrent matrices whose eigenvalues sit at roots of unity. Each step rotates stored symbols, and each one resurfaces at its turn. The Legendre Memory Unit (2019) stores a sliding window of the past in a fixed rotated basis by design.
- **Closest method.** Karuvally et al. (2023) define a trained network's memory slots by taking the readout and pushing it repeatedly through the recurrent matrix. They assume the shift structure in order to build a basis. They do not test it against separately trained readouts.
- Rotations encode position or value elsewhere too: the "clock" in modular-addition transformers (Nanda et al. 2023; Zhong et al. 2023).

**What is known about this network.** Keane (January to March 2026) found most of the surrounding facts. The readout is "a DFT-like decoder", and its rows behave like a wheel. The effective rotation within the active neurons is about 0.7 to 0.8 radians per step, which is close to our 40 degrees (0.70 radians). The predicted position counts down one step at a time: "pred(t) = S_pos + (9 - t)". That countdown is exactly what our identity predicts. This link is our inference; Keane did not state it. But Keane then decomposed the full recurrent matrix and found no chain along its first off-diagonal. He concluded "Not a Delay Line". That test only finds open-ended chains. A cyclic shift is a pure rotation and has no off-diagonal part, so the test cannot see it. He also used the whole matrix rather than the matrix within one on/off pattern. His results and ours therefore do not conflict on data, but his headline should not be cited as settled.

ARC's hand-built 22-neuron network uses a literal shift register: each memory neuron copies the next one, and output k reads neuron k. There the identity holds exactly in the neuron basis. The trained network appears to do the same in a rotated basis. That is a useful sentence for the paper.

**Verdict: partly new.** Known: delay lines in trained networks, rotated bases, readouts built by propagation, and on this network the wheel, the decoder and the countdown. New, as far as we found: (1) a pass-or-fail test on readout rows trained separately, (2) applied within one activation pattern of a ReLU network, and (3) the resulting correction of Keane's "Not a Delay Line".

## (B) A hand-built network of the trained size, role by role

**What is known.**

- **Rebuilding to test an explanation.** Curve Circuits (Cammarata et al. 2021) set the weights of a blank network by hand to test their account of curve detectors. They did not look at the original weights while doing so. Their replacement curve detectors recovered more than half the accuracy lost by removing the originals. Their build copies one circuit, not a whole network of the same size. A 2025 review lists hand-coded "drop in" replacements as an open problem (Sharkey et al. 2025).
- **Hand-written solutions in the trained architecture.** Gromov (2023) writes down analytic weights for the same two-layer network trained on modular arithmetic. Gradient descent finds the same features. Henaff et al. (2016) show that trained recurrent networks sit close to their explicit solutions. Both match at the level of features or eigenvalues, not neuron by neuron. In Gromov's case the trained network beats the hand-written one at equal width. Ours goes the other way: the build gets 98.9% against the trained network's 95.3%.
- **Earlier builds for this task.** ARC's build uses 22 neurons, and ARC says it has "not produced a correspondence" with most trained neurons. Chen's build uses 21 neurons. Chen says three trained neurons "have their exact counterparts" in it, and calls the four negative-input neurons "very entangled".
- **Other directions that are not hand-built mirrors.** Compiled models run the other way: program first, then weights (Tracr, InterpBench). Other methods replace parts with learned components: causal scrubbing resamples activations, and circuit tracing uses trained transcoders. Program synthesis turns a trained network into Python code automatically (Michaud et al. 2024). Some studies write hand-made proxies or rubrics for single neurons or features (Bricken et al. 2023; Gao 2026).

**Why matching the size matters.** Different trained networks learn different circuits for the same task (Chughtai et al. 2023; Zhong et al. 2023). A larger build can solve the task without reproducing the trained network's tricks. A build of the same size that copies each role shows those roles are enough. The same-size constraint is a narrow criterion, though. Its value lies in this argument, not in the size itself.

**Verdict: partly new.** Hand-built tests of explanations, same-architecture analytic solutions, and partial neuron matches for this task are all known. We found no earlier same-size, every-neuron, rule-built rebuild of a trained network used to test an explanation. This search could easily miss such a case in neuroscience, where rebuilding trained networks as reduced models is common.

## Limits of this search

The search used web search, arXiv, Distill, the LessWrong API and Keane's repository (all 49 documents listed, the relevant ones read). Google Scholar and citation tracking were not used. Two papers were blocked to direct download: Ganguli et al. 2008 and Goldman 2009. Their quotes come from a web-fetch tool that read the PubMed Central pages. Treat those quotes as near-verbatim. Two leads were not opened, and are unverified: Dubreuil et al. 2022 (reduced low-rank versions of trained networks) and Pollock and Jazayeri 2020 (designing network weights to produce chosen dynamics). Either could be a closer precedent for (B).
